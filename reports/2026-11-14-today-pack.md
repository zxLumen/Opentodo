### 实现落点

- `web/today.js`：数据（检测场/车管站/官方原文材料）+ 内联 HTML/CSS/JS 渲染；仅 Node 内置能力。
- `web/server.js`：新增 `GET /today`（含 `/today/`），复用 `resolveScope`；`/api/op` 增加可选 `baseRevision` 乐观并发校验，冲突返回 409 + 最新 `data`；`/favicon.ico` 返回 204，消除 404 控制台错误。
- `web/ops.js`：`runOp(..., { baseRevision })` 在文件锁内核对 revision。
- `mcp/lib/store.js`：`normalizeItem` 保留未知字段（如 `note`），且历史 `completed` 条目的 `completedAt=null` 不再被补写——否则一次写入会把其他 5 条历史完成项和 6 条备注改掉，无法满足「其他条目 0 变动」。
- `web/test/today.test.mjs`：6 项新测试（到期解析、逾期天数、渲染字段、XSS、note 保留、409 + 完整 9→7 流程）。
- `web/Dockerfile`：运行镜像补拷 `web/today.js`。

## 关键取舍

1. **「已拖 33 天」按精确时长取整**：`createdAt 2026-10-11T11:04Z` 到 `2026-11-14 08:13 +08:00` 为 33.55 天，`floor` 得 33；按日历日差会显示 34。页面同时显示「到期日 2026-11-14（今天到期）」和「已拖 33 天」，避免把「逾期 0 天」误读成没拖。
2. **费用只写官方能支撑的部分**：官方指南明确「核发机动车检验合格标志：不收费」；四个检测场页面均未公示安检/尾气价格，因此逐条写「未查到（检测费）」，没有拿旧文或市场价冒充官方价。
3. **检测场选 4 家、车管站选 2 家**：覆盖朝阳/丰台/海淀/昌平，且每个字段都有交管局正文页可逐条回链。海淀车管站只有 `map.beijing.gov.cn` 的官方地图页，不在你指定的三个来源域名内，因此没有为凑数收进来。
4. **材料按原文摘录，不把「身份证」硬塞成必交**：官方「十、提交的资料」没有把车主本人身份证列为上线检验必交材料；页面在原文清单后单独标注「身份证在代理/免检车身份证明处要求，建议随身带」，既覆盖你的清单，也不改写官方原文。
5. **写入走现有 `/api/op` + `setStatus`**：只增加可选 `baseRevision`，不新增写接口；客户端写前重读 `/api/state`，409 时用返回的最新 revision 重试 1 次（实测 `[409, 200]`）。并发校验在 `store.update` 的文件锁内完成，不是「先查后写」的假乐观锁。
6. **顺手修了共享 store 的写入副作用**：不修 `normalizeItem` 的话，任何一次 Web 写入都会丢掉 `note` 并把历史完成项的 `completedAt` 补成当前时间，直接违反「其他条目 0 变动」。该修复向后兼容，`mcp` 11 项测试全过。
7. **部署走仓库既有链路**：提交 → GitHub Actions 构建 `ghcr.io/zxlumen/opentodo-web:latest` → 服务器 `compose pull/up -d --no-deps opentodo`；生产 `todos.json` 只读，未点任何「办完」。
8. **页面零外部资源**：CSS/JS 全内联，图标用 data URI，`/favicon.ico` 返回 204；390px 下 0 console error、0 横向滚动。
